# Licence log

Every third-party source that was reviewed for Split Ways, and every data file the project ships that
is not code, gets a row here **before** anything is derived from it or added to the repo. Licence words
are quoted verbatim. A source is only listed as used when its Decision column says it may be used.
`assets/ASSETS.md` keeps the per-file table of shipped assets. Each section below has one table row
per source.
